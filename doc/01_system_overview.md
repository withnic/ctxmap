01. システム概要 (System Overview)
プロジェクト目的
AIがコードベースを探索する際、ファイル全体を何度も Read してトークンを浪費するのを防ぐため、コードの「骨格（シグネチャ・型定義）」と「依存関係」だけを軽量なテキストで標準出力に返すCLIツール ctxmap を作成する。
技術要件
言語: Go
モジュール名: github.com/withnic/ctxmap
依存関係: 外部依存は最小限（できれば標準ライブラリのみ）。CGOなしでクロスコンパイル・go install が通ること。
Goパーサー: 標準ライブラリの go/ast, go/parser, go/token を使用。
TS/JSパーサー: .ts, .tsx, .js, .jsx に対して、正規表現または軽量パーサーで export された関数・クラス・interface・type・import文を抽出。
サブコマンド仕様
1. ctxmap map [path]
指定パス（デフォルト .）を再帰的に走査。
出力内容:
型定義（struct, interface, type）
関数・メソッドのシグネチャ（本体 { ... } は省略）
宣言直上のDocコメント
出力形式: トークン効率の良いコンパクトなMarkdown形式（JSON不可）。
オプション: --include-tests フラグがない限り、テストファイル（*_test.go, *.spec.ts, *.test.ts）は除外。
2. ctxmap deps [path]
指定パスのファイルが import しているローカルモジュール／パッケージの依存関係を抽出。
出力形式: コンパクトなリスト形式。
オプション: --target <ファイルパスまたはパッケージ名> を指定した場合、その対象に依存しているファイル（被参照元）と依存先だけを絞り込んで表示。
3. ctxmap slice <symbol> [path]
指定した関数名・メソッド名・型名（<symbol>）の定義ブロック（実装本体を含む）を検索。
該当箇所のコード、ファイルパス、行番号をピンポイントで出力。
